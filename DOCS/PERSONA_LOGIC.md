
# Persona Modeling Logic

## 1. 社會階層與經濟模型 (Socio-Economic Model)
基於 `data/job_lexicon.ts` 與 `data/open_data/income_distribution.ts` 的定義。

### 1.1 收入階級 (Income Classes) - MECE 5級制
系統不再使用模糊的 High/Medium/Low，而是依據財政部稅務級距定義以下五種生存狀態：
- **Survival (生存線)**: < P10。入不敷出，對價格極度敏感，無任何非必要消費能力。
- **Tight (拮据線)**: P10 - P25。手頭緊，雖有消費慾望但常需取捨 (Trade-off)，容易產生「報復性小額消費」。
- **Stable (小康/穩定)**: Median。一般受薪階級，追求 CP 值與規畫性消費。
- **Affluent (富裕)**: P90。有餘裕進行投資或體驗型消費，重視品質大於價格。
- **Elite (頂層)**: > P99。資產階級或高階金領，消費決策與一般大眾邏輯脫鉤。

### 1.2 勞動型態 (Labor Modes)
勞動型態決定了「金錢來源」的性質與「時間結構」：
- **Standard (受僱體制)**: 朝九晚五，收入穩定。對「規律」有依賴。
- **Gig (零工/輪班)**: 時間碎片化，收入波動。對「現金流」敏感 (e.g. 外送員、作業員)。
- **Autonomous (自主/接案)**: 工時彈性但界線模糊。公私帳混淆 (e.g. 房仲、設計師)。
- **Domestic (家務勞動)**: 時間被他人(小孩/長輩)切割。消費多為家庭採購。
- **Student (在學)**: 時間結構僵固(白天) + 極度自由(深夜)。高慾望低收入。
- **Inactive (非勞動)**: 退休或待業。時間極多，對通膨與存款水位焦慮。

## 2. 社會動力學模型 (Social Dynamics)
基於 `data/taiwan_sociology.ts`，系統推論使用者的深層心理：

### 2.1 金錢來源心理 (Money Type Psychology)
- **Blood_Sweat (血汗錢)**: 用勞力/工時換取的每一分錢。對「浪費」極度敏感，花錢需要強烈的理由。
- **Easy_Windfall (快錢/資產)**: 房東、二代、投資致富。對價格敏感度低，重視「情緒價值」與「爽感」。
- **Stable_Salary (穩定月薪)**: 定期進帳。重視「預算規畫」與「分期付款」。
- **Cash_Flow (現金流)**: 業務、老闆。重視「周轉效率」與「槓桿」，敢於負債。

### 2.2 生存策略 (Coping Strategy)
當「面子需求 (Face Score)」與「實際收入」發生衝突時的應對機制：
- **Mom_Bank (靠爸族)**: 高消費、低收入 (學生/二代)。行為特徵：無金錢概念，先買再說。
- **Eat_Cheap_Wear_Rich (精緻窮)**: 高面子產業 (業務/KOL) 但低底薪。行為特徵：外表光鮮，私下吃泡麵，重視可視化消費。
- **Stealth_Wealth (隱形富豪)**: 低面子需求、高資產 (工程師/房東)。行為特徵：穿著隨意，對奢侈品無感，但在意被當「盤子」。
- **Installment_King (分期之王)**: 關注「月付額」而非「總價」，透過現金流管理來維持生活品質。
- **Compensatory (補償性消費)**: 高勞力/輪班工作者，透過高價享受 (按摩/大餐) 來彌補身心疲勞。

## 3. 作息指紋 (Time Fingerprints)
基於 `data/open_data/time_patterns.ts`，系統識別以下特殊作息原型：

- **Tech_Fab_Shift (產線輪班)**: 高紀律性，工作時完全離線，下班後報復性熬夜。
- **Tech_Crunch_Dev (責任制軟體)**: 晚起，深夜是產出高峰，作息向後平移。
- **Delivery_Driver (外送物流)**: 與一般人作息反相。用餐時段忙碌，下午/深夜活躍。
- **Night_Entertainment (夜生活)**: 日夜顛倒，夕陽後起床。
- **Retired_Elder (退休長輩)**: 極早起 (05:00)，白天有大量碎片時間，晚上極早睡。

## 4. 現實校準 (Reality Check)
系統會比對「自我宣稱的角色 (Role)」與「行為數據證據 (Evidence)」：
- **High/Medium**: 角色與行為一致。
- **Delusional (認知偏離)**: 自認為高階層 (CEO/貴婦) 但消費力低落。
  - **行為修正**: 嘴巴上嫌棄平價品 (用「品味不符」當藉口)，但實際上買不起高價品。
- **Insolvent (負債風險)**: 低收入但出現高額消費。
  - **行為修正**: 衝動消費後伴隨強烈的焦慮或後悔，搜尋「分期」、「貸款」。
- **Anomaly (異常)**: 學生/年輕人卻有極高消費力 (通常歸類為靠爸族或幣圈新貴)。

## 5. 轉化潛力評級 (Conversion Logic)
- **Drive (推力)**: 慾望強度 + 急迫感。
- **Resistance (阻力)**: (價格敏感度 + 改變慣性) * 現實係數。
  - **現實係數 (Reality Coeff)**: 若判定為 `Insolvent` 或 `Delusional`，阻力會被強制加權，導致「想買但買不了」。
